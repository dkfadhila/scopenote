# Proposal background

`scopenote-background.png` is an A4-ratio portrait PNG with an alpha channel, generated for ScopeNote using OpenAI image generation under the project owner's direction. It contains no text or logo. The PDF draws it on white paper at 40% opacity so the artwork is visible while the document text stays clear.

The client-side PDF uses Lato Regular and Bold, distributed with their SIL Open Font License in `public/fonts/OFL-Lato.txt`. Font sources: https://github.com/google/fonts/tree/main/ofl/lato.
